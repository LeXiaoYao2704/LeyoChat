LeyoChat 0.4.0 更新说明

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 消息服务器与发送链路
   - 完善消息服务器优先的发送路径，直聊、群聊和群文件消息在服务器确认后
     同步本地消息状态，减少发送成功但本地状态未更新的情况。
   - 优化群文件服务配置解析，未单独配置群文件服务时默认复用消息服务器地址，
     降低部署环境里群文件和消息服务地址不一致带来的配置成本。
   - 增加发送链路阶段日志，便于定位消息创建、入库、服务器确认和 P2P 兜底
     各阶段的问题。
   - 修复消息服务路径丢失群聊 @、回复发送人和回复正文的问题；新旧客户端
     混合使用时，旧客户端继续走原有字段，新客户端可恢复完整消息语义。
   - 修复消息服务轮询兜底收到消息后，前台会话不能及时回传已读的问题。

2. 崩溃诊断与稳定性
   - 新增独立启动器。客户端异常退出后会自动重启，并按 2 秒、10 秒、30 秒
     逐步退避；短时间连续失败超过限制后停止重启，避免无限循环。
   - 崩溃重启后可恢复窗口、页面、原会话和未发送的文本、回复或编辑上下文，
     不会自动重发消息，也不会自动恢复文件传输任务。
   - 自动恢复用于减轻崩溃对使用过程的影响，不代表所有历史崩溃根因已经修复；
     dmp、客户端日志和启动器日志仍会保留用于继续分析。
   - 移除会掩盖真实异常的发送入口和主事件循环兜底捕获，保留阶段日志，
     让现场 dmp 和日志能暴露原始崩溃原因。
   - 加强直聊文本发送的本地消息创建和入库诊断，便于继续追踪真实环境中的
     string too long 类崩溃。
   - 清理连接关闭路径中的指针登记，降低退出或断线时的悬挂引用风险。

3. 界面与交互修复
   - 修复通过消息服务同步收到新消息时，客户端最小化或处于后台却不触发
     任务栏闪烁和托盘提醒的问题。
   - 修复窗口最小化、隐藏到托盘或处于后台时，仅因会话仍被选中就自动回传
     “已读”的问题；P2P、事件流和轮询统一使用前台可见门禁。
   - 修复同一群连续多条服务消息被按会话合并后，提醒发送人、数量和预览不准；
     服务端窗口抖动提醒现在会恢复并抖动窗口。
   - 修复群消息 @ 元数据写入数据库后重新加载读不出来的问题。
   - 修复服务路径群文件卡片未同步到共享资源目录的问题。
   - 服务贴纸图片先缓存到本地文件，再从消息数据库移除 base64 大字段；
     客户端贴纸限制 8 MB，消息服务请求限制 16 MB，避免异常数据无界增长。
   - 修复顶部全局搜索弹窗首次点击后仍需再次点击输入框的问题，弹出后可直接输入。
   - 增强搜索输入框焦点视觉提示，降低光标闪烁导致的焦点不明确感。
   - 调整群信息和群文件相关入口，减少旧群文件服务设置页与当前消息服务器配置
     并存造成的理解成本。

4. 测试与验证
   - 补充已读门禁、服务消息 @/回复、贴纸缓存、结构化提醒、群文件资源同步、
     消息请求大小限制及发送路由相关回归测试。
   - 打包继续归档 PDB 符号文件，方便后续现场 dmp 分析。

LeyoChat 0.3.3 更新说明

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 崩溃/稳定性修复
   - 修复 TLS write notifier 损坏导致的崩溃。
   - 修复 sendBatch 释放后使用（UAF）导致的崩溃。
   - 修复多处空指针守卫缺失引发的崩溃。
   - 修复 PeerConnection 缓冲区溢出导致大文件传输卡死。

2. 新功能
   - 群成员退出系统消息：成员退出时显示"xxx 退出了群聊"，
     与微信/钉钉行为一致。
   - 快速建群：右键联系人可直接发起建群并预选该成员。
   - 聊天记录异步导出：大量消息导出不再冻结 UI。

3. Bug 修复
   - 修复群成员退出后剩余成员 UI 不刷新（头部人数/成员列表）。
   - 修复导出菜单下拉样式异常（改用 ElaMenu）。
   - 修复 LeyoFileService 数据库路径迁移后自启动找不到旧数据。
   - 修复文件预览控件大文件加载逻辑。

4. 改进
   - FileService 启动参数新增 onlyoffice-url，
     支持自定义 OnlyOffice 服务地址。
   - 群文件服务配置持久化（RemoteFileServiceSettings）。

LeyoChat 0.3.2 更新说明

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 新功能
   - 消息表情回应（Reaction）：长按消息可发送表情回应，
     显示参与者名称悬浮提示，支持 OK 手势等多种表情。
   - 转发详情预览：转发消息前可预览包裹卡片内容。
   - 聊天记录导出：支持 TXT/HTML 两种格式导出当前会话。
   - 文件接收通知：收到文件时任务栏闪烁 + 托盘气泡提醒，
     与普通消息行为一致。
   - 群成员在线优先排序：在线成员自动排列在列表顶部。
   - 回复引用跳转：点击回复引用块自动滚动到原消息并闪烁高亮。

2. Bug 修复
   - 修复拖拽文件发送失效：延迟 OLE IDropTarget 注册时机，
     增加 GetPropW 验证和重试机制，确保 ElaAppBar 样式变更后
     拖拽仍可用。
   - 修复群消息预览不一致：SQL CASE 守卫 + 内存时间戳合并，
     防止旧消息覆盖新预览。
   - 修复最小化恢复卡顿：精简窗口状态调用（6次→3次），
     消除冗余 re-layout 和 DWM 刷新。
   - 修复截图工具栏溢出屏幕右边界。
   - 修复个人资料弹窗鼠标移入时消失。
   - 修复转发消息显示 #000000 颜色及多选勾选框不出现。
   - 修复群聊已读回执未发送。
   - 修复图片气泡内容溢出。

3. 性能优化
   - 文件接收异步化：FileReceiveWorker 将文件块 I/O 和
     DB 写入移至独立线程，主线程不再阻塞。
   - 已读回执 SQL 移出主线程，减少消息处理延迟。
   - 大群消息扇出批量发送（20条/批），避免 UI 卡顿。
   - 文件传输速度 + ETA 显示：EMA 平滑速度跟踪。

4. UI 改进
   - 移除会话搜索栏，界面更简洁。
   - 安装程序默认保留现有文件服务，升级时自动检测并勾选。

LeyoChat 0.3.1 更新说明

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 新功能：存储管理
   - 设置页新增「存储管理」卡片，可管理文件接收路径。
   - 新增数据清理功能，按分类（日志/消息/文件/图片）
     查看磁盘占用，支持勾选批量删除历史数据。

2. Bug 修复
   - 修复文件拖放失效：Qt 6 无边框窗口 OLE IDropTarget
     未正确注册，拖放文件到聊天窗口无响应。
   - 修复跨会话粘贴图片发送失败：从其他会话复制图片后
     粘贴显示正常但发送为空消息（HTML 剪贴板 base64 提取）。
   - 修复「取消」按钮显示截断：ElaPushButton 自定义绘制
     忽略 stylesheet，改用标准 QPushButton 使扁平样式生效。
   - 修复搜索卡顿/崩溃：会话列表过滤增加索引缓存 + 150ms 防抖。
   - 修复安装包版本号不同步：installer 从 CMake 获取版本号。
   - 修复文本气泡最小宽度过大（132px→60px）。
   - 修复双击非图片区域误触发图片查看器。
   - 修复拖拽文件到输入框无响应（viewport acceptDrops 传递）。

3. 优化
   - 输入框组件重构，代码结构更清晰。
   - 会话列表 delegate 绘制迁移至 QStyledItemDelegate。
   - 会话切换性能优化，减少切换延迟。
   - 异步图片缩略图缓存 + 模糊占位 + 淡入动画。
   - 通知页签视觉简化，去除多余背景框。
